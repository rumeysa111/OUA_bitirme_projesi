# Kahve Kaşifi

## About the Project

**Kahve Kaşifi** is a mobile application designed to assist users in discovering their ideal coffee. The app uses a dynamic question system to provide personalized coffee recommendations, offering a wide range of options tailored to individual preferences.

---

## Features

- **Dynamic Question System**: Adapts questions based on user preferences.
- **Personalized Recommendations**: Suggests coffees that suit individual tastes.
- **Wide Coffee Selection**: From traditional brews to specialty options.
- **User-Friendly Design**: Intuitive interface for seamless navigation.

---

## Technologies Used

- **Frontend**: Flutter
- **Backend**: Firebase Authentication, Firestore
- **Design Tools**: Figma
- **Project Management**: Trello (Used for sprint planning and task tracking)
